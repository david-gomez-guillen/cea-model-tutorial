# THALASSA tutorial model

A model of screening for a hypothetical chronic disease, built up stage by stage
in the model integration tutorial of THALASSA.

This branch is **Setup 2: A conda environment of your own**, which [`tutorial.md`](tutorial.md) explains, and
the Overview tab of the app shows. Each stage is a branch of this repository.

- [`logic-3-strata`](https://github.com/david-gomez-guillen/cea-model-tutorial/tree/logic-3-strata)
