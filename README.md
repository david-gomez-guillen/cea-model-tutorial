# THALASSA tutorial model

A model of screening for a hypothetical chronic disease, built up stage by stage
in the model integration tutorial of THALASSA.

This branch is **Stage 2: Describing parameters and strategies**, which [the tutorial](https://david-gomez-guillen.github.io/thalassa/docs/tutorial/stage-2-describing.html)
explains. Each stage is a branch of this repository:

- [`stage-1-minimal`](https://david-gomez-guillen.github.io/thalassa/docs/tutorial/stage-1-minimal.html)
- [`stage-2-describing`](https://david-gomez-guillen.github.io/thalassa/docs/tutorial/stage-2-describing.html)
- [`stage-3-strata`](https://david-gomez-guillen.github.io/thalassa/docs/tutorial/stage-3-strata.html)
- [`stage-4-calibration`](https://david-gomez-guillen.github.io/thalassa/docs/tutorial/stage-4-calibration.html)
- [`stage-5-constraints`](https://david-gomez-guillen.github.io/thalassa/docs/tutorial/stage-5-constraints.html)
- [`stage-6-presentation`](https://david-gomez-guillen.github.io/thalassa/docs/tutorial/stage-6-presentation.html)
- [`stage-7-packages`](https://david-gomez-guillen.github.io/thalassa/docs/tutorial/stage-7-packages.html)

Run `Rscript try_model.R` to simulate the model from R, without the app.
